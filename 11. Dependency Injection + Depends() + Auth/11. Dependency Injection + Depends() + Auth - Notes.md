# 11. Dependency Injection + Depends() + Auth

## What this code does
Introduces **dependency injection** via `Depends()` — a way to share reusable logic (like auth checks) across routes without copy-pasting code.

```python
from fastapi import FastAPI, Depends, Header, HTTPException

app = FastAPI()

def verify_token(token: str = Header(None)):
    if token != "mysecerttoken":
        raise HTTPException(status_code=401, detail="Unauthorized")
    return {"message": "Authorized User"}

@app.get("/secure_data")
def secure_data(user = Depends(verify_token)):
    return {
        "message": "Secure Data Accessed",
        "user": user
    }
```

## Key concepts

**1. The commented-out examples build up the idea gradually**
It's worth reading the comments top to bottom — they show the progression:
- `common_logic()` used with `Depends()` in one route → basic idea: "run this function before my route, give me its result"
- `get_current_user()` reused across **two** routes (`/profile` and `/dashboard`) → shows the real value: **the same dependency can be shared across multiple endpoints**
- `verify_token()` (the final, active version) → applies this to a real use case: authentication

**2. What `Depends()` actually does**
```python
def secure_data(user = Depends(verify_token)):
```
Before `secure_data` runs, FastAPI:
1. Calls `verify_token(...)` first
2. Passes its return value into `secure_data` as the `user` argument
3. Only then runs the route's own code

This is **dependency injection**: instead of the route manually calling `verify_token()` inside its body, FastAPI "injects" the result automatically.

**3. `Header()` — reading HTTP headers**
```python
def verify_token(token: str = Header(None)):
```
Just like `Query()` reads query params, `Header()` tells FastAPI to pull this value from the **request headers** instead of the URL or body.
- A request needs to send a header like: `token: mysecerttoken`
- `Header(None)` gives it a default of `None` if the header is missing (so it doesn't error out before your own check runs)

**4. The auth pattern**
```python
def verify_token(token: str = Header(None)):
    if token != "mysecerttoken":
        raise HTTPException(status_code=401, detail="Unauthorized")
    return {"message": "Authorized User"}
```
This is a simplified authentication gate:
- Wrong/missing token → `401 Unauthorized` is raised, and the route function **never even runs**
- Correct token → returns a value that gets passed into the route as `user`

Because `raise` happens *inside the dependency*, FastAPI stops the whole request right there — the actual route logic (`secure_data`) is fully protected without needing any auth code inside it.

**5. Why this matters — reusability**
Imagine 10 routes all needing "must be logged in." Without `Depends()`, you'd repeat the token-check code in every single route. With it:
```python
@app.get("/route1")
def route1(user = Depends(verify_token)): ...

@app.get("/route2")
def route2(user = Depends(verify_token)): ...
```
Each route just declares `Depends(verify_token)` and gets the exact same protection — one function, reused everywhere, one place to update if the auth logic changes.

## Quick recap
- `Depends(some_function)` → runs `some_function` before the route, and injects its return value as an argument
- The same dependency function can be reused across as many routes as needed
- `Header(default)` → reads a value from HTTP request headers, instead of path/query/body
- Raising an exception *inside* a dependency blocks the route entirely before its own code runs — a clean way to build reusable auth/validation gates
