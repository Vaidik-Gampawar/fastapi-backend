# 18. DELETE Operation with Database

## What this code does
Completes full CRUD with a database backend — the "D" in CRUD, removing a row from the `todos` table.

```python
@app.delete("/todos/{todo_id}")
def delete_todo(todo_id: int, db: Session = Depends(get_db)):
    todo = db.query(Todo).filter(Todo.id == todo_id).first()

    if not todo:
        raise HTTPException(status_code=404, detail="Todo Not Found")

    db.delete(todo)
    db.commit()

    return {"message": "Todo Delete"}
```

🎉 **With this, your Todo app now has full, database-backed CRUD** — create, read (all + one), update, and delete — all persisted in `test.db` via SQLAlchemy.

## Key concepts

**1. The now-familiar three-step shape**
By this point the pattern should feel very recognizable — every operation that touches a *specific* row follows the same shape:
```python
todo = db.query(Todo).filter(Todo.id == todo_id).first()   # 1. find it
if not todo:                                                 # 2. guard
    raise HTTPException(status_code=404, detail="Todo Not Found")
# 3. do something with it (mutate + commit, or delete + commit)
```
Create is really the only one that doesn't need the "find first" step, since it's not working with an existing row.

**2. `db.delete(todo)`**
```python
db.delete(todo)
```
Marks this specific object for deletion — similar to how `db.add()` staged a new object for insertion in the CREATE lecture. Nothing is removed from the database yet at this point.

**3. `db.commit()` — same role as always**
Just like in create and update, `commit()` is the step that actually executes the SQL (this time, `DELETE FROM todos WHERE id = ...`) and permanently saves the change.

**4. No `db.refresh()` needed here**
Unlike create/update, there's nothing to refresh — the object no longer exists in the database, so there's no updated state to sync back into it.

## Full CRUD, side-by-side
| Operation | Find first? | Core step | Finish |
|---|---|---|---|
| **Create** | No | `Todo(...)` → `db.add(todo)` | `commit()` + `refresh()` |
| **Read** | — | `db.query(Todo).all()` or `.filter(...).first()` | *(no write)* |
| **Update** | Yes | mutate `todo.field = value` | `commit()` + `refresh()` |
| **Delete** | Yes | `db.delete(todo)` | `commit()` (no refresh) |
