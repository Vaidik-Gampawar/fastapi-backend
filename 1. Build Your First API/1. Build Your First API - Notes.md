# 1. Build Your First API

## What this code does
A minimal FastAPI app with three GET routes that each return a JSON response.

```python
from fastapi import FastAPI

app = FastAPI()

@app.get("/")
def home():
    return {"message": "hello world"}

@app.get("/about")
def about():
    return {"message": "This is about page"}

@app.get("/users")
def users():
    return {"users": ["John", "Alex", "Bob"]}
```

## Key concepts

**1. `FastAPI()` instance**
`app = FastAPI()` creates the core application object. This `app` variable is what Uvicorn (the server) actually runs.

**2. Path operation decorators**
`@app.get("/path")` tells FastAPI: "when someone sends an HTTP GET request to this path, run the function below."
- `.get()` → for reading data
- (Later you'll meet `.post()`, `.put()`, `.delete()` for creating/updating/deleting)

**3. Path operation functions**
The function right under the decorator (`home`, `about`, `users`) is called a **path operation function**. Its return value is automatically converted to JSON — you don't need to manually serialize anything.

**4. Automatic JSON conversion**
Returning a Python `dict` (e.g. `{"message": "hello world"}`) is enough. FastAPI handles the conversion to a proper JSON HTTP response behind the scenes.

**5. Routes defined**
| Method | Path      | Returns                              |
|--------|-----------|---------------------------------------|
| GET    | `/`       | `{"message": "hello world"}`          |
| GET    | `/about`  | `{"message": "This is about page"}`   |
| GET    | `/users`  | `{"users": ["John", "Alex", "Bob"]}`  |

## How to run it
```bash
uvicorn main:app --reload
```
- `main` = filename (`main.py`)
- `app` = the FastAPI instance variable
- `--reload` = auto-restarts the server when you save changes (dev only)

## Bonus (worth trying next)
FastAPI auto-generates interactive API docs — once the server is running, visit:
- `http://127.0.0.1:8000/docs` (Swagger UI)
- `http://127.0.0.1:8000/redoc` (ReDoc)

## Quick recap
- `FastAPI()` → creates the app
- `@app.get(path)` → defines a route for GET requests
- Function returns a dict → FastAPI serializes it to JSON automatically
- `uvicorn main:app --reload` → runs the dev server
