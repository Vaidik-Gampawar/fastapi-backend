# 2. Path Parameter + Dynamic Route + Validation

## What this code does
Introduces a **dynamic route** — a URL that changes based on what the user passes in, instead of being fixed like `/about`.

```python
from fastapi import FastAPI

app = FastAPI()

@app.get("/users/{user_id}")
def get_user(user_id: str):
    return {"user_id": user_id}
```

## Key concepts

**1. Path parameters — `{user_id}`**
The curly braces in `"/users/{user_id}"` mark a **variable segment** of the URL. Whatever the user types there gets captured.
- `/users/42` → `user_id = "42"`
- `/users/john` → `user_id = "john"`

**2. Matching function argument**
The path parameter name must **match the function parameter name exactly**.
```python
@app.get("/users/{user_id}")
def get_user(user_id: str):
```
`{user_id}` in the path ↔ `user_id` in the function signature. FastAPI wires these together automatically.

**3. Type hints = automatic validation**
`user_id: str` isn't just for readability — FastAPI actually **enforces** it.
- Here it's typed as `str`, so any value in the URL works (numbers, text, etc. all get read as strings).
- If you'd typed `user_id: int` instead, FastAPI would automatically reject non-numeric input (like `/users/abc`) with a `422 Unprocessable Entity` error — no manual validation code needed.

This is one of FastAPI's biggest selling points: **type hints double as request validation.**

**4. Dynamic vs static routes**
- Static route (from lecture 1): `/about` → always the same path
- Dynamic route (this lecture): `/users/{user_id}` → path changes per request, and the value flows into your function

## Try this next
Swap `user_id: str` for `user_id: int` and hit `/users/abc` in the browser — you'll see FastAPI's automatic validation error in action.

## Quick recap
- `{param_name}` in the route path → creates a path parameter
- Function argument name must match the `{param_name}` in the path
- Type hint (`str`, `int`, etc.) → FastAPI validates incoming data against it automatically
- Wrong type → FastAPI returns a `422` error before your function even runs
